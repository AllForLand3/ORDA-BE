# 산 선택 (어느 산으로 갈까요?)

로그인하면 처음 보이는 화면이다. 코스를 탐색할 산을 고른다.

1. 검색창("산 이름을 검색해 보세요")에 산 이름 일부를 입력하면 목록이 걸러진다.
2. 목록은 한 페이지에 10개씩 나오고 [이전], [다음]으로 넘긴다.
3. 산 카드를 누르면 선택되고 지도가 그 산으로 이동한다. 카드에는 이름, 주소, 높이가 나온다.
   - 같은 카드를 다시 누르거나 [선택 취소], Esc 키로 선택을 풀 수 있다.
4. 아래 [코스 탐색 설정]을 누르면 코스 탐색 설정 화면으로 이동한다.
   - 산을 고르지 않았거나, 산 정보를 확인 중이거나, 코스 탐색을 제공하지 않는 산이면 버튼이 꺼져 있다.

- 현재 목록에 나오는 산은 관악산, 북한산, 도봉산, 청계산, 수락산, 불암산, 아차산, 북악산, 용마산 9곳이다.
- 카드 사진은 모든 산에 같은 이미지가 쓰인다.
- "검색 결과가 없어요."가 나오면 [검색 초기화]를 누른다.
