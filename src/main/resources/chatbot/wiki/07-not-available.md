# 아직 제공하지 않는 기능

아래 기능은 화면에 버튼이나 항목이 보여도 아직 동작하지 않는다.

| 기능 | 현재 상태 |
|---|---|
| 비밀번호 찾기, 소셜 로그인(Google, 카카오톡, Apple) | 아직 연결되지 않음 |
| 약관 전문 보기 | 준비 중 |
| 닉네임 수정, 비밀번호 변경, 회원 탈퇴 | 없음 |
| 홈 상단 메뉴(서비스 소개, 주요 기능, 코스 추천, 이용 안내) | 눌러도 이동하지 않음 |
| 출발지와 도착지 장소 검색 | 예시 장소 3곳만 고를 수 있음. 지도에서 직접 고르는 것은 가능 |
| 등산 수준, 완만한 경사, 비교 정보를 반영한 탐색 | 거리 우선으로만 탐색 |
| 경로 후보 여러 개 | 후보 1개 |
| 경로의 예상 시간, 누적 상승 | "정보 없음"으로 표시 |
| 경로 탐색 결과의 지형 분석 | 미제공 |
| 경로 탐색 결과를 내 코스로 저장 | 없음 |
| 코스 내보내기(GPX, GeoJSON) | 미제공 |
| GPX 파일 가져오기, 지도에서 코스 직접 그리기 | 미지원 |
| 코스의 경로나 산 수정 | 이름과 메모만 수정 가능 |
| 9곳 외 다른 산 | 관악산, 북한산, 도봉산, 청계산, 수락산, 불암산, 아차산, 북악산, 용마산만 지원 |
| 날씨, 등산로 통제, 실시간 혼잡도 | 제공하지 않음. 국립공원공단, 지자체 공지를 확인 |
