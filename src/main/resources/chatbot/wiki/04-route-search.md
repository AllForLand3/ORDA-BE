# 경로 탐색 (코스 탐색 설정과 결과)

출발지와 도착지를 정하면 두 지점을 잇는 등산로 경로를 찾아 준다. 산 선택 화면에서 [코스 탐색 설정]을 눌러 시작한다.

## 1단계: 출발지와 도착지

출발지와 도착지를 각각 아래 두 방법 중 하나로 정한다.

- 검색: "출발지를 검색해주세요"를 누르고 장소를 고른다.
  - 실제 장소 검색은 아직 없고, 예시 장소 3곳(서울대 건설환경종합연구소 앞, 관악산 연주대, 관악산 서울대입구)만 고를 수 있다.
  - 예시 장소는 모두 관악산에 있다. 다른 산을 골랐다면 지도에서 선택으로 출발지와 도착지를 정한다.
- 지도에서 선택: 지도 핀 버튼([출발지 지도에서 선택])을 누른 뒤 지도를 누른다.

위치를 고르면 "이 위치를 출발지로 설정할까요?"가 나오고, 가장 가까운 등산로 지점을 자동으로 찾는다.

- 찾으면 "가까운 등산로 지점에 연결돼요 · 선택 위치에서 약 N m"가 나오고 [출발지로 설정]을 누를 수 있다.
- 선택한 위치에서 300m 안에 등산로가 없으면 연결할 수 없다. 등산로에 더 가까운 곳을 다시 고른다.
- 지도에는 고른 위치와 연결된 등산로 지점이 따로 표시된다.
- 출발지와 도착지가 같은 등산로 지점에 연결되면 다음으로 넘어갈 수 없다. 서로 떨어진 위치를 고른다.
- 두 지점이 모두 연결되면 [다음 →]이 켜진다.

## 2단계: 나의 등산 수준

- 초급, 중급, 숙련 중 하나를 고른다.
- 지금은 경로 탐색 결과에 반영되지 않는다.

## 3단계: 어떤 코스를 원하시나요?

- 탐색 기준: 거리 우선, 완만한 경사
- 비교 정보: 화장실, 주차장, 쉼터, 조망점, 위험 관련 지점
- 탐색 기준과 비교 정보를 각각 하나 이상 골라야 [맞춤 경로 탐색하기]가 켜진다.
- 지금은 거리 우선(가장 짧은 경로)으로만 탐색한다. 완만한 경사, 등산 수준, 비교 정보는 아직 결과에 반영되지 않는다.

## 경로 탐색 결과

[맞춤 경로 탐색하기]를 누르면 경로 탐색 결과 화면이 열린다.

- 코스 비교 탭
  - 지금은 거리 우선 경로 후보 1개가 나온다.
  - 카드에 거리, 예상 시간, 누적 상승이 나온다. 예상 시간과 누적 상승은 아직 데이터가 없어 "정보 없음"으로 나온다.
  - 카드의 계단과 시설 수는 경로에서 200m 안에 있는 지점과 시설을 센 값이다.
  - 지도에 경로 선이 그려진다.
- 지형 분석 탭: 탐색 결과의 지형 분석은 아직 제공하지 않는다.
- 주변 시설 탭: 경로에서 200m 안의 화장실, 주차장, 쉼터를 가까운 순으로 보여 준다. 이름을 누르면 지도가 그 위치로 이동한다.

## 자주 생기는 상황

- "이동 가능한 경로를 찾지 못했어요": 두 지점을 잇는 등산로가 없다. 출발지나 도착지를 바꿔 다시 탐색한다.
- "출발지와 도착지가 같아요": 서로 다른 지점을 고른다.
- 조건을 바꾸려면 브라우저 뒤로 가기로 설정 화면에 돌아간다. 고른 지점과 조건은 그대로 남아 있다.
- 탐색 결과를 내 코스로 저장하는 기능은 아직 없다.
- 결과 화면 하단의 [맞춤 경로] 탭을 누르면 실제 결과가 아닌 예시 화면("경로 분석 결과", 예시 코스 3개)이 열린다. 실제 탐색은 산 선택 화면에서 다시 시작한다.
